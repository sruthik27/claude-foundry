# all-mods

Dependency-only bundle of all 11 mods. Includes features that make model calls and experimental Self-drive, which stays inactive until its command is invoked. See the root guide for permissions, usage and removal.

## Install

```bash
claude plugin install all-mods --marketplace sruthik27/claude-foundry
```

Requires Claude Code 2.1.296+. Reload plugins or start a new session after installation.

## Try it

```text
claude plugin install all-mods --marketplace sruthik27/claude-foundry
```
