# starter-kit

Dependency-only bundle: Lumen, Insight Pane, Changes, Goal Meter and Live Progress. Each remains an independent plugin. See the root guide for updates and removal.

## Install

```bash
claude plugin install starter-kit --marketplace sruthik27/claude-code-mods
```

Requires Claude Code 2.1.296+. Reload plugins or start a new session after installation.

## Try it

```text
claude plugin install starter-kit --marketplace sruthik27/claude-code-mods
```
