# goal-meter

Shows goal estimates and task progress above the prompt. Claude can report a goal, phase and percentage; task completion also advances the bar. No direct auxiliary model calls.

## Install

```bash
claude plugin install goal-meter --marketplace sruthik27/claude-foundry
```

Requires Claude Code 2.1.296+. Reload plugins or start a new session after installation.

## Try it

```text
Ask Claude to complete a task with tracked steps.
```
