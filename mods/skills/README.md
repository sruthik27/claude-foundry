# skills

Suggests up to three installed skills below the prompt, and removes a suggestion once the skill is loaded. Uses model-backed selection. It does not install skills.

## Install

```bash
claude plugin install skills --marketplace sruthik27/claude-foundry
```

Requires Claude Code 2.1.296+. Reload plugins or start a new session after installation.

## Try it

```text
Type a request relevant to one of your installed skills.
```
