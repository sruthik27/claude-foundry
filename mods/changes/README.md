# changes

Browse concept groups, files and symbols. Select code in the viewer to ask a question or request a change. Branch scope uses Git diffs. Shell edit capture is heuristic and bounded; it is not a complete filesystem audit. Fallback group labels use Haiku.

## Install

```bash
claude plugin install changes --marketplace sruthik27/claude-code-mods
```

Requires Claude Code 2.1.296+. Reload plugins or start a new session after installation.

## Try it

```text
/changes
/changes branch
```
