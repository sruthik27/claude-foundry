# session-namer

Periodically proposes a session name from the work, without replacing a title you set yourself. Uses the session model and consumes model usage.

## Install

```bash
claude plugin install session-namer --marketplace sruthik27/claude-code-mods
```

Requires Claude Code 2.1.296+. Reload plugins or start a new session after installation.

## Try it

```text
Work normally, then use /resume to find the session.
```
