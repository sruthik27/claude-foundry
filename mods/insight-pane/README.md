# insight-pane

Toggle the Intel pane. Cards summarize concepts, decisions, root causes, gotchas, facts and risks. Cards are persisted per session and capped by importance. A Haiku fallback can extract cards when Claude did not supply them.

## Install

```bash
claude plugin install insight-pane --marketplace sruthik27/claude-code-mods
```

Requires Claude Code 2.1.296+. Reload plugins or start a new session after installation.

## Try it

```text
/intel
```
